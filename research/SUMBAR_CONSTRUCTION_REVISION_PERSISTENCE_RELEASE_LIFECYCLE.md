# Sumbar construction revision persistence and release lifecycle

## Question

The existing historical reconstruction already established that `Statistik Indonesia 2005/2006` explicitly revised the Sumatera Barat construction values for 2001-2003. The remaining release-vintage question is whether the revised values are merely a one-yearbook anomaly or whether BPS subsequently carried them into a dedicated construction-series publication.

This checkpoint also separates that historical revision from ordinary maturation of values that were explicitly preliminary or estimated in the earlier vintage.

## Later dedicated BPS series

BPS publication `Statistik Tahunan Perusahaan Konstruksi 2002-2006` has:

- catalog number `6301003`;
- publication number `05340.0704`;
- official metadata release date `2007-05-15`;
- PDF preface text `Jakarta, Nopember 2007`;
- a preserved metadata/preface date conflict, so no exact physical publication-day inference is made;
- a foreword stating that the 2002-2006 construction statistical series results from Annual Construction Establishment Surveys.

Table 14, `Nilai Konstruksi yang Diselesaikan Menurut Propinsi / Value of Construction Completed by Province`, gives the following Sumatera Barat values in thousand rupiahs:

| year | dedicated series value | status in later table |
|---|---:|---|
| 2002 | 717,299,178 | no provisional marker |
| 2003 | 844,516,928 | no provisional marker |
| 2004 | 956,619,300 | no provisional marker |
| 2005 | 1,315,105,562 | no provisional marker |
| 2006 | 1,324,786,176 | preliminary |

## Persistence of the historical revision

`Statistik Indonesia 2005/2006` had already reported:

- 2002: `717,299,178`, explicitly revised;
- 2003: `844,516,928`, explicitly revised.

The later dedicated annual-survey series reproduces both values **exactly**. Therefore the 2002-2003 revised vintage is not reasonably classified as a one-off display/transcription anomaly of one statistical yearbook. It persisted into a later BPS construction-series release.

This finding strengthens the status of the revised vintage. It does **not** identify why the revision happened.

## Ordinary release maturation is different

The same comparison behaves differently for the years whose earlier values were provisional:

- 2004 moves from `932,441,815` preliminary to `956,619,300`, a change of `24,177,485` or about `2.592922%`;
- 2005 moves from `1,046,561,944` estimated to `1,315,105,562`, a change of `268,543,618` or about `25.659601%`.

Those changes occur from explicitly preliminary/estimated earlier states into later unmarked values and are therefore classified as release maturation rather than as evidence of the same historical revision event that affected 2002-2003.

The classification is about publication-state behavior. It does not claim that every unmarked later value is metaphysically final or immune to future revision.

## Effect on the mechanism candidate

The existing candidate mechanism remains:

`sampling_frame_refresh_plus_qualification_based_expansion_reestimation`

with status:

`operationally_plausible_period_link_confirmed_causal_revision_link_unproven`

This checkpoint adds one useful constraint: the large revised 2002-2003 levels became an adopted later BPS series vintage. That makes explanations based on a one-off yearbook typo/display error substantially less credible.

It still does not establish a causal link to the end-2005 directory update because no contemporaneous revision note, weighting formula, old/new Sumatera Barat frame counts, or reproducible bridge has been recovered.

## Gates that remain closed

Nothing in this checkpoint authorizes:

- silent overwrite of old vintages;
- construction of one continuous 1998-2006 trajectory across the break;
- a cross-vintage bridge;
- a common-ratio backcast;
- attribution of the historical revision to the 2005 directory update;
- a causal mechanism claim;
- Panel v3 integration of a bridged historical construction trajectory.

The correct next research target remains contemporaneous 2005/2006 methodology or revision documentation capable of linking the adopted revised vintage to a specific operational mechanism.
