# 25-Day Research Foundation Sprint

## Goal
Finish a trustworthy research foundation, not a polished product.

### Days 1–3 — Scope and catalog
- freeze research questions and claim taxonomy;
- establish source policy and indicator ontology;
- build the initial source catalog;
- define canonical geography and time metadata.

### Days 4–8 — Ingestion foundation
- create reproducible source-specific ingestion patterns;
- implement raw/processed separation;
- add provenance and validation schemas;
- ingest the first high-value official sources.

### Days 6–10 — Geography
- build canonical province/regency/city registry;
- record historical names and validity periods;
- design boundary-version and crosswalk tables;
- add core geospatial reference layers.

### Days 8–13 — Historical reconstruction
- inventory historical statistical publications;
- record methodology/classification breaks;
- build a structured historical-event register;
- keep reconstructed values distinct from observations.

### Days 11–15 — Climate and disaster layer
- ingest rainfall/climate observations where practical;
- ingest disaster events and risk layers;
- model hazard, exposure, vulnerability, and loss as separate concepts;
- prepare a West Sumatra case-study dataset.

### Days 14–17 — Exploratory analysis
- build long-run descriptive series;
- inspect missingness, breaks, volatility, and divergence;
- compare West Sumatra with Indonesian regional distributions.

### Days 17–19 — Peer discovery
- construct transparent peers from baseline characteristics;
- optionally test PCA/clustering as exploratory similarity tools;
- document sensitivity to peer selection.

### Days 19–21 — Baseline potential-gap models
- fit simple expected-performance baselines;
- test one interpretable tree-based benchmark if useful;
- prototype a frontier/efficiency model;
- label all outputs as estimates, not facts.

### Days 21–23 — Focused explanatory study
- choose one question with adequate data;
- define comparison design and assumptions;
- run diagnostics and robustness checks;
- document what the study can and cannot establish.

### Days 23–24 — 2026 climate/disaster showcase
- assemble one recent West Sumatra/Padang-area case study;
- connect rainfall/hazard evidence to exposure, infrastructure, and development context;
- avoid attributing losses to a single cause without evidence.

### Day 25 — Freeze v0.1 research foundation
Expected outputs:
- research charter and methodology;
- source catalog;
- indicator framework;
- canonical geography design;
- 40–60 core indicators targeted, with a validated subset already ingested;
- comparative Indonesian panel prototype;
- exploratory notebook/report;
- one expected-performance/frontier prototype;
- one focused explanatory case study;
- one climate/disaster case study;
- documented limitations and next steps.

## Explicitly deferred
A production dashboard, LLM research assistant, complex orchestration, real-time ingestion, and large-scale policy optimization are deferred until the research layer is trustworthy.
